# flight-tracker

Трекер полётов: получает данные о самолётах через OpenSky Network API, сохраняет в JSON, фильтрует и выводит статистику. Проект написан на Python 3.12 с использованием Poetry для управления зависимостями и pytest для тестирования.

## Возможности

- Получение списка самолётов по стране регистрации (через OpenSky API).
- Конвертация сырых данных API в объекты класса `Aeroplane`.
- Сохранение и загрузка данных в JSON-файл через `JSONSaver`.
- Фильтрация и базовая статистика по полётам.
- Покрытие кода тестами (pytest + coverage).

## Требования

- Python 3.12
- Poetry (для управления зависимостями и виртуальным окружением)
